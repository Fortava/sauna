# BÖRN

Shopify theme for [bornsauna.com.au](https://bornsauna.com.au).

| Path | Purpose |
| --- | --- |
| [`theme/`](./theme/) | Online Store 2.0 theme source |
| [`born-shopify-theme.zip`](./born-shopify-theme.zip) | Upload-ready zip for Shopify Admin |

## Publish

1. **Online Store → Themes → Add theme → Upload zip** → `born-shopify-theme.zip`
2. **Customize** → Hero product → select **Premium Wool Sauna Hat**
3. Theme settings → Contact page, Instagram, SEO defaults
4. Preview, then **Publish**

Full editing + SEO notes: [`theme/README.md`](./theme/README.md)
